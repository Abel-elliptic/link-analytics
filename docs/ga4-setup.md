# GA4 で短縮リンク別の年齢・性別を見る手順

> この手順は Google の公式ヘルプに基づく概要です。画面の名前や配置は変わることがあるため、最新の情報は公式ヘルプで確認してください。

## 前提として知っておくこと
- 短縮URLのクリック自体には年齢・性別の情報は含まれません。GA4 のユーザー属性（年齢・性別）は **Googleシグナル** を使った推計値です。
- 推計値は**集計としてのみ**見られます。どのクリックが何歳かといった、1件ずつのデータは取得できません。
- 少数のデータは **データのしきい値** によりレポートで表示されません。
  - 参考: Google アナリティクス ヘルプ「Google シグナルのデータ収集を有効にする」「データのしきい値について」（support.google.com/analytics）

## 1. GA4 プロパティを作成し、遷移先サイトにタグを入れる
1. https://analytics.google.com で「管理」→「プロパティを作成」を選びます。
2. 「データストリーム」→「ウェブ」で遷移先サイトのURLを登録し、**測定ID（G-XXXXXXX）** を確認します。
3. 遷移先サイトの全ページの `<head>` に、表示された Google タグ（gtag.js）を貼ります（WordPress ならプラグインやテーマの設定から入れても構いません）。
4. GA4 の「リアルタイム」レポートで、自分のアクセスが計測されているか確認します。

## 2. Googleシグナルを有効にする
「管理」→「データの収集と修正」→「データ収集」で、Googleシグナルのデータ収集を有効にします。

## 3. 短縮リンク別に見る
このシステムは、遷移先URLに次のパラメータを自動で付けます。
- `utm_source` / `utm_medium` / `utm_campaign`: リンク作成時に入力した値
- `utm_content`: **スラッグ（短縮リンクのID）**

見る手順は次のとおりです。
- 「レポート」→「ユーザー属性」→「ユーザー属性の詳細」を開きます。
- 「フィルタを追加」で「セッションの手動広告コンテンツ」（= utm_content）を指定し、対象のスラッグで絞り込みます。
  - フィルタに出てこない場合は、「探索」で自由形式のレポートを作り、ディメンション「セッションの手動広告コンテンツ」と「年齢」「性別」を掛け合わせて見てください。

## 4. 法令面の対応（要確認）
GA4 を導入すると、閲覧者の情報が Google に送られます。日本の電気通信事業法の「外部送信規律」（2023年6月施行）の対象になる事業者は、通知や公表が必要です。該当するかどうかは総務省の解説ページを確認し、必要に応じて専門家に相談してください。雛形は `docs/privacy-template.md` にあります。
