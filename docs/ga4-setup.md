# GA4 連携（短縮リンク別に年齢・性別を見る）

管理画面の「GA4連携」ページ（`/dashboard/ga4`）と同じ内容です。画面の名称は GA4 の更新で変わることがあります。

## しくみ
ziplink は遷移先URLに UTM を自動付与して転送します（`utm_content` = スラッグ）。遷移先サイトに GA4 を入れると、GA4 側でこの値ごとに年齢・性別（**集計の推計値**）を見られます。ziplink と GA4 の間に API キー等の接続設定は不要です。クリック1件ごとの年齢・性別は取得できません。

## 手順
1. **プロパティ作成**: GA4「管理」→「作成」→「プロパティ」
2. **データストリーム作成**: 「管理」→「データの収集と修正」→「データ ストリーム」→「ストリームを追加」→「ウェブ」→「ウェブサイトの URL」に**遷移先サイト（自社サイト）のドメイン**を入力（ziplink の URL ではない）→「作成して続行」→「ストリームの詳細」で測定ID（G-）を控える
3. **タグ設置**: 遷移先サイトの全ページの `<head>` 直後に Google タグを貼る（管理画面の「GA4連携」で測定IDを入れると生成。GA4 の「タグの実装手順を表示」→「手動でインストール」と同形式）。最長30分後に「リアルタイム」で確認
4. **Google シグナル**: 「管理」→「データの収集と修正」→「データの収集」→「Google シグナルのデータ収集を有効にする」をオン
5. **見る**: 「探索」→「空白」→ ディメンション「セッションの手動広告コンテンツ」「年齢」「性別」、指標「アクティブ ユーザー」→ 行に年齢/性別、フィルタで「セッションの手動広告コンテンツ」完全一致＝スラッグ

出典（1〜4）: Google アナリティクス ヘルプ [9304153](https://support.google.com/analytics/answer/9304153?hl=ja)、[9445345](https://support.google.com/analytics/answer/9445345?hl=ja)。
手順5のディメンション名・探索の画面表記は公式ヘルプでは未確認（解説記事に基づく）。

## 注意
- 少人数のデータは「データのしきい値」で非表示になります
- UTM は大文字・小文字を区別します
- GA4 導入時は電気通信事業法の外部送信規律への対応が必要になる場合があります（雛形: `docs/privacy-template.md`、法的助言ではありません）
